# 永劫无间 · 征神之路 魂玉配装工具

一个**纯静态**网页（无需服务器、无需构建、无依赖），用于搭配征神之路魂玉、
汇总面板属性，并估算配装的期望伤害。自适应桌面 / 平板 / 手机，界面主色调可自定义。

## 使用

直接用浏览器打开 `index.html` 即可（`file://` 亦可正常运行）。

> 想了解设计思路、计算模型推导，以及开发过程中踩过的坑和修复过程，
> 见 [DEVLOG.md](DEVLOG.md)。

- **魂玉池**：34 颗魂玉，搜索 + 「全部 / 招式专精」筛选，点击或拖拽佩戴。魂玉本身**不带元素**。
- **配装**：默认 **7 个配装槽位**（可调 4~8）。每颗魂玉包含：
- **染元素**：魂玉本身**不带元素**（魂玉池里也看不到任何元素图标），佩戴后可单独选择
  ⚡雷 / ❄冰 / ☠毒，再点一次取消。染好后该魂玉图标左下角会显示对应的元素角标。
  顶部「全体染元素」可一键统一（`通用·夺魂` 无法染元素，会自动跳过）。
  - **4 个词条槽位**：每一格都能选普通词条或稀有词条，**稀有词条不限数量**
    （可以 4 格全合道，也可以三种稀有各来一条）。同一颗玉内普通词条不重复。
    同一颗魂玉内不会出现重复的普通词条。
  - 若 4 格中带有【合道】，该魂玉的普通词条自动 ×1.5 并高亮显示。
- **属性 / 期望**：实时汇总全部数值并给出期望伤害；卸下魂玉会立即重算。
- **推荐配装**：内置三套模板（见下）。
- **主题**：顶部「主题」按钮 → 弹出取色圆环，转盘选色 / 拖明度条 / 点预设色块，
  点「应用」即保存；「恢复默认」回到淡蓝。配色存本地，下次打开不会闪回默认色。
- **保存 / 我的配装**：点「保存」给当前配装**起个名字**存档，之后在「我的配装」里随时
  载入或删除（重名会覆盖原来的那套）。工作区的改动会自动保存，下次打开还是上次的状态。
- **导出 / 导入**：导出可得到 JSON 与**分享链接**。
- 分享链接形如 `index.html#preset=benlei` 或 `index.html#build=<base64>`，打开即还原配装；
  移动端可加 `&tab=build` 直接定位到配装面板。

### 普通词条（满数值）

暴击率 3% · 暴击伤害 25% · 冰爆伤害加成 30% · 天雷伤害加成 30% · 毒爆伤害加成 30% ·
攻击 4% · 对首领伤害增加 5% · 远程武器招式增伤 5% · 神射值积攒效率 10%

### 稀有词条（满数值）

> 每颗魂玉固定 4 个词条槽位，稀有词条与普通词条**共用这 4 格**，且**不限制稀有词条数量**。

- **合道**：此魂玉上的副属性额外增加 50%（该魂玉的普通词条 ×1.5）
- **化气**：触发元素后减少技能冷却 25%
- **枚卜**：触发两次暴击判定的概率 +20%，并取其中更优结果生效

## 计算模型

| 项目 | 公式 |
|---|---|
| 攻击力 | `基础攻击力 × (1 + 攻击力加成)` |
| 暴击倍率 | `1 + (基础暴击伤害 + 暴击伤害词条) / 100`（默认基础 100% 即 2 倍） |
| 枚卜等效暴击率 | `p + q·p·(1 − p)`，`q` = 枚卜概率 |
| 每颗魂玉词条位 | 固定 4 格，普通词条与稀有词条共用，稀有词条不限数量 |
| 普攻期望 | `攻击力 × 普攻倍率 × 对首领增伤 × 远程招式增伤 × 有效暴击期望` |
| 元素期望 | `攻击力 × 元素倍率 × (1 + 输出元素对应爆伤加成) × 段数修正 × 元素暴击期望` |
| 元素 DPS | `元素期望 × 元素频率 × (1 + 元素积累效率) × 冰爆冷却修正` |
| 技能 DPS | `技能期望 × 技能频率 ÷ (1 − 技能冷却缩减)` |
| 相对基准 | 同参数下空配装的综合 DPS 记为 **100** |

所有基准值（基础攻击力、倍率、频率、基础暴击、输出元素等）都可在「计算参数」中调整。

> ⚠️ 伤害为**模型估算**，用于横向对比配装强度，不代表游戏内实际数值。
> 截图中没有明确数值的机制（流星、毒沼、天雷反射等）不计入期望伤害，
> 仅在「已激活特殊效果」中列出提示。

## 文件结构

```
index.html      页面结构
styles.css      样式（淡蓝色调，自适应桌面 / 平板 / 手机）
data.js         魂玉、词条、推荐配装数据（改这里即可扩展）
app.js          计算引擎 + 渲染 + 交互
assets/jade/    15 个魂玉图标（已抹掉截图里烤进去的元素角标）
assets/element/ 3 个元素图标（雷 / 冰 / 毒，已抠成透明 PNG）
```

### 扩展魂玉

在 `data.js` 的 `JADES` 中追加一项即可，`mods` 的键名对应统计字段：

```js
{
  id: 'xxx', name: '新魂玉', score: 6000, rarity: '极',
  category: '征神魂玉',                 // 或 '招式专精魂玉'
  icon: 'assets/jade/xxx.png',
  brief: '一句话描述',
  bullets: ['效果条目（会显示为标签）'],
  mods: { iceDmg: 40, critRate: 5 },    // 参与计算
  specials: ['无明确数值的机制说明'],
}
```

可用的 `mods` 键：`atkPct` `critRate` `critDmg` `elemCritRate` `iceDmg` `thunderDmg`
`poisonDmg` `elemAccum` `bossDmg` `rangedDmg` `divineEff` `skillDmg` `cdr` `meibu`
`frostCap` `poisonLayerNeed` `iceDmgMul` `iceCdr` `rangedSelfMul`（可累加），
`elemDmgAny`（加到该魂玉**所染元素**的伤害加成上），
以及 `iceHits` / `rangedHits`（取最大值）、`cannotImbue`（布尔标记，禁止染元素）。
